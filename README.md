# 俄罗斯音乐留学平台 · Gift Edition V5

面向中文音乐学习者的俄罗斯音乐留学信息平台。当前版本整合俄罗斯音乐院校、个人申请计划、声乐曲库、音乐史、俄中音乐百科与作品材料预检，并针对 Vercel、iPhone 与 iPad 做了部署前收口。

## 当前能力

- **院校数据库**：9 所核心音乐学院；城市、关键词与 2026/27 核实状态筛选。
- **院校申请档案**：官方招生入口、专业/层级、声乐考试、曲目准备、俄语要求、时间线与官方来源。
- **我的申请**：收藏、目标院校、六项准备清单、总体/单校进度和个人备注；无需登录，默认保存在当前浏览器。
- **俄罗斯声乐曲库**：核心作曲家浪漫曲、练声曲与公开资源入口。
- **音乐史知识库**：作曲家、音乐学派、歌剧、浪漫曲与历史时期。
- **俄中音乐百科**：术语与专业概念检索。
- **作品材料预检 Beta**：在浏览器本地检查音频格式、体积、时长与命名，不上传录音。

## V5 部署级调整

- Next.js 从旧版升级到 **15.5.24 Maintenance LTS**。
- 动态路由已按 Next 15 的异步 `params` 方式兼容。
- 增加 `vercel.json`、`.vercelignore` 与 Node 版本约束。
- 增加 `viewportFit: cover`、Safari safe-area、动态视口高度与减少动态效果偏好支持。
- `localStorage` 不可用时，“我的申请”会退化为当前标签页内存模式，不会直接崩溃。
- 增加 iOS 180×180 Apple Touch Icon 与 192/512 Web App 图标。
- 移除未被任何页面引用的旧百科数据和旧视觉素材，源码包从约 10 MB 减至约 5 MB。
- 移除歌剧/浪漫曲专题对 Google Fonts 的运行时依赖，网络受限时也能保持可读。
- 修正歌剧专题中指向不存在作曲家详情页的遗留链接。
- 增加 `npm run check` 部署前静态验收命令。

## 院校数据的时间含义

当前日期为 2026 年 9 月，因此 2026/27 招生周期大多已经结束。本项目将 2026/27 官方资料作为“已核实基准”，供下一轮提前准备；不会把已结束日期伪装成 2027/28 的确定安排。

2027/28 新规则发布后，应更新 `app/data/conservatories.js`。来源与维护方法见 `docs/ADMISSIONS_DATA.md`。

## 本地运行

推荐 Node.js 20：

```bash
npm install
npm run check
npm run dev
```

打开 `http://localhost:3000`。

## 正式构建

```bash
npm install
npm run check
npm run build
npm start
```

## Vercel

项目根目录已包含 `vercel.json`，Vercel 应自动识别为 Next.js；不需要数据库，也没有必需环境变量。部署说明见 `DEPLOY.md`。

## 数据与隐私

“我的申请”默认使用浏览器 `localStorage`。清理站点数据、换浏览器或换设备不会自动同步；如果 Safari/浏览器禁止持久化存储，页面仍可在当前标签页继续使用，但关闭页面后数据可能丢失。

源码不包含飞书 App Secret、API Key 或其他真实密钥。作品材料预检不会把用户选择的音频上传到服务器。

曲库中的外部链接可能跳转至 IMSLP、notarhiv.ru 等公开资料页。使用、下载或再分发前，应以目标页面的版权与授权说明为准。
